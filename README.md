## Демо 1. Обработка заявок на закупку (Python)

Скрипт читает заявки из CSV, проверяет данные (пустые поля, e-mail, дата, количество, цена, дубли) и раскладывает их по статусам: автоодобрена, на согласование, дубль, отклонена. Формирует сводку и файлы по статусам.

- Только стандартная библиотека Python 3.8+.
- Уведомления в режиме dry-run: только печатаются, в коде нет отправки писем и сообщений. Адреса `@example.com` выдуманные.
- Проверено запуском на 12 тестовых заявках и 7 автотестами `unittest`.
- В README демо описана схема того же процесса для n8n и Make. Готовый сценарий там **не собирался**.

Запуск:
```
cd 01_python_automation_demo
python3 process_requests.py sample_requests.csv
python3 -m unittest -v
```

## Демо 2. QA: отчёт об ошибке и тест-кейсы

Двухстраничный образец: оформленный отчёт об ошибке (вымышленная ошибка счётчика корзины) и 14 тест-кейсов для Android-приложения интернет-магазина. Приложение «Demo Shop» вымышленное, реальное тестирование на телефоне не проводилось.
